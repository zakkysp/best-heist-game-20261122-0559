The Midnight Vault — a top-down 2D canvas heist game, built for make.fun's "Make the best heist game" bounty. One thief, one bank vault at night, three patrolling guards with vision cones, three sweeping security cameras, six treasures worth $6,000 — and one way out.

Move with WASD or the arrow keys. Click to toss a coin and distract a guard (3 coins). Grab at least $4,000 of loot, then slip out through the EXIT. Stay out of the yellow cones and the red camera sweeps; hide in the dark carpet when the alarm climbs. If a guard lays a hand on you, the night is over.

## Run it

```sh
python3 -m http.server --directory game 8080
# then open http://localhost:8080 in desktop Chrome
```
